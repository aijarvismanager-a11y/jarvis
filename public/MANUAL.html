AIオーケストラ 使い方

作りたいものを書くと、AI が計画を立て、あなたが確認してから作業を進めるアプリです。

始める前に

パソコンに Claude Code が入っていて、ログイン済みであることが必要です。ホーム画面の上に「使えるかどうか」が出ます。出ていなければ、表示の案内に従ってください。

基本の流れ

  1. ホームで作りたいものを書いて「開発を開始」を押します。
  2. AI が出した計画を読み、よければ「この計画で開始」を押します。直したいときは希望を書いて「修正して再提案」を押します。
  3. AI が作業します。画面の一番上の「次にやること」を見れば、いま自分がやることが分かります。
  4. 終わったら「動かして確認」で試します。続きは「新しい依頼」で頼みます。

削除や公開など取り返しにくい作業の前には、AI があなたに確認を求めます(許可)。何もしなければ実行されません。

画面の見かた

タブ見られること
ホーム次にやること、いまの依頼、新しい依頼の入力、元のフォルダとの同期、動かして確認。
進み具合いまの依頼が全体のどこまで進んだか。作業ごとの状況と、各作業でできたファイル。
これまでの記録過去に出した依頼の一覧と、何が起きたかの履歴。
できたものAI が作ったファイルを選んで読めます(ここでは編集できません)。
設定ブラウザ上のAIを使うかどうか、使えるAIの一覧、プロジェクトの削除(一番下)。ふだんは触らなくて大丈夫です。

すでにあるフォルダを使う(取り込み)

画面右上の「既存プロジェクトを取り込む」でフォルダを選ぶと、中身をコピーしてこのアプリで作業します。元のフォルダは、あなたが許可するまで変わりません。

  • 大きすぎるフォルダは、重いフォルダ(node_modules など)を除いて取り込めます。
  • 作業の結果を元へ戻すときは「元のフォルダとの同期」で、違いを見て、書き込むファイルを選びます。書き込む前に元のファイルは自動でバックアップされ、あとから元に戻せます。
  • 同じフォルダをもう一度取り込むと、新しく作らず、前のプロジェクトを開きます。

プロジェクトを消す

試しに取り込んだプロジェクトなどは、「設定」タブの一番下の「このプロジェクトを削除」で消せます。消えるのはこのアプリの中のコピーと記録だけで、取り込み元の元のフォルダは消えません。実行中の依頼があるときは、先に止めてください。

困ったとき

「うまくいかなかった作業があります」と出た
ホームの赤い「失敗の理由」の枠に、何が起きたかと対処法が出ます。内容を読んで「計画をやり直す」(または失敗した作業の「この作業をやり直す」)を押してください。「これまでの記録」の履歴にも残ります。
計画がなかなか出ない
計画づくりには通常 1〜2 分かかります。できあがると画面が自動で切り替わります。5 分以上たっても変わらないときは、いったん中止して、もう一度依頼を出してください。
AI が間違えた
「変更内容を見る」で何が変わったか確認し、「この作業の変更を元に戻す」でその作業の前に戻せます。
途中で方針を変えたい・止めたい
実行中は「一時停止」「方針を変える」「中止」が使えます。完了済みの作業は残ります。
「サーバーに接続できません」と出る
アプリが起動していません。起動用のファイル(start-ai-orchestrator.bat)で起動し直してください。
「サーバーが古いコードのまま」と出る
表示のボタン「サーバーを再起動」を押してください。実行中の依頼は再起動後に自動で再開します。
お金はかかる?
このアプリ自体は無料です。AI の利用は、あなたの Claude Code の契約(利用枠)から使われます。

用語

依頼
AI に頼む1回のまとまり。1つのプロジェクトに何度でも出せます。
計画
依頼を受けて AI が立てる作業の予定。始める前に必ずあなたが確認します。
作業
計画の1つ1つの手順(設計 → 実装 → レビュー など)。
許可
取り返しにくい作業の前に、AI があなたに確認を求める仕組み。
取り込み / 同期
既存フォルダをコピーして読み込むこと / コピーと元の違いを確認して元へ反映すること。
