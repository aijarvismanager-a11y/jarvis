# Gage 実機検証の手順書(あなたが試す用)

調査・設計(2026-10-29〜30)で「実機で確かめるまで、決められない」とされた項目を、試せる順にまとめたものです。
出どころは、`projects/gage_df3cd6e6/design/` の3つの設計書(`desktop-boundary-redesign.md` §8、`thumbnail-pipeline-redesign.md` §12、`inter-gage-move-plan-a-vs-b.md` §6)です。
**ここに書いた「合格の目安」は、設計書の合格基準をそのまま写したものです。Gage の画面の名前や操作は、実際の画面に合わせて読み替えてください。**

## 始める前に(安全)
- いま使っている Gage の設定ファイル(`fences.json` など)を、**先に別の場所へコピー**しておく。
- 試すときは、大事なファイルをデスクトップに置かない。**捨ててよいテスト用のファイルとフォルダ**を5〜10個つくって使う。
- 1項目ずつ試して、結果を末尾の表に書く。**わからないときは「不明」と書いてよい**(推測で埋めない)。
- 結果の表を私に貼ってもらえれば、設計の「暫定方針」を「確定」か「やり直し」に分けます。

## まず、Gage を起動するまで(PowerShell で、1行ずつ)
1. 設定の控えを取る: `Copy-Item $env:APPDATAGage $env:USERPROFILEDesktopGage-設定の控え -Recurse`
2. 元の Gage のフォルダで起動する: `cd C:UserscrossDesktopGage` → `dotnet run --project src/Fence.App -c Release`
3. 終わったら、トレイのアイコンから Gage を終了する(控えは、問題がなければ消してよい)。
