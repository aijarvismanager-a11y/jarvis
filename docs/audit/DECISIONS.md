## D-11 詳細: SQLiteドライバのスパイク結果(2026-10-23、Node v24.22.1 / npm 11.19.1 / Windows 11)
| 項目 | better-sqlite3 13.0.3 | node:sqlite(組み込み) |
|---|---|---|
| 導入 | `npm install` 4秒。**プリビルドバイナリ**が入り、C++コンパイラ不要(この機は `cl` 無し) | 依存なし |
| 動作 | メモリDBでCRUD成功 | メモリDBでCRUD成功。WAL有効、外部キー強制、ROLLBACK、2万件INSERT(トランザクション内)104ms を確認 |
| 配布リスク | Nodeのバージョンに対応するプリビルドが無いと、コンパイラ無しの配布先PCで`npm install`が失敗しうる | Nodeに同梱。ただし `node:sqlite` はNodeの開発中機能(実験的警告が出る版あり) |
| 判定 | 動作する(代替) | **採用** |

採用理由: 本アプリはZIP配布で、`start-ai-orchestrator.bat` がNodeを自動導入し`npm install`する(コンパイラの無いPCを想定)。ネイティブ依存を増やさない方が壊れにくい。リポジトリ層を薄いインターフェースに隔離し、問題が出れば better-sqlite3 へ差し替える。
未確認: (1) 配布用フォールバックのNode 22.13.0(bat内MSI)での動作。`node:sqlite` はv22.13.0でフラグ不要になった版だが実機未検証 (2) APIの安定性(将来のNodeで変更されうる) (3) 他PCでのbetter-sqlite3プリビルド取得。→ Phase 1の最初に `engines`(>=22.13)指定とbatのNode版確認を行う。
