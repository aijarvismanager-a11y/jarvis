## 10. 実機での実測（2026-11-11・画面を実際に起動して確認）

起動は `dotnet src\HyperPlayer.App\bin\Debug\net8.0-windows\HyperPlayer.App.dll`（バージョン表示 v1.2.2）。窓を 1000x600 にして撮影・操作した。ffmpeg は未検出の環境。

| # | 項目 | 実測の結果 |
| --- | --- | --- |
| (1) | 1000x600 の崩れ | **不具合あり（使いにくさ）**。横スクロールや重なりは出ていない。ただし (a) スタジオ全画面で「必要なツールが見つかりません」のパネルが内容部分の約4割を占め、ダウンロード画面は最初の表示に URL 欄の頭しか見えない。(b) スタジオ左ナビの「設定」が下に隠れ、ナビ内のスクロールが必要。(c) プレイヤーの右列は縦スクロールになり、「無劣化カット」の実行・バージョン情報・ダウンロードのボタンはスクロールしないと見えない。 |
| (2) | Tab 順・フォーカス枠 | **一部確認**。ボタンにフォーカスが当たると、水色 2px の角丸枠が見える（「メディアスタジオ」「動画ファイルを開く」で確認）。Tab 順の通し確認は未実施。 |
| (3) | ドロップ | 未確認（エクスプローラーからのドラッグを自動操作できなかった）。ファイル選択からの読み込みは成功。 |

| (5) | 速度・音量・字幕 | **一部確認**。`sample.mp4` は再生でき、映像と字幕（"External subtitle test line"）が表示された。**不具合候補**: 再生中も再生ボタンが ▶ のまま、終了時刻が 0:00 のまま（長さを読めていない）、シークバーが最初から右端にある。速度・音量・字幕の切替の効果は未確認。 |

**不具合の候補（優先順）**
1. ffmpeg 未検出パネルが小さい窓で場所を取りすぎる（スクロールで消せるが、最初の表示で本体が見えない）。1 行に折りたたむか、画面ごとの先頭に置かない。
2. 再生中の表示: ▶ が ⏸ に変わらない、長さが 0:00、シークバーが動かない。
3. スタジオ左ナビの「設定」が 600 高さで隠れる。
4. 全画面が画面全体に広がらない。
