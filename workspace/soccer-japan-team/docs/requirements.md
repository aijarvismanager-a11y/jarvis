# 🇯🇵 サッカー日本代表クロニクル

# 要件定義書

**Document Version:** 1.0
**Status:** Initial Requirements
**対象:** サッカー日本代表情報サイト
**想定開発環境:** Windows 11 / Claude Code
**基本方針:** 日本代表の「現在」と「歴史」を一つのデータベースでつなぐ

---

# 1. プロジェクト概要

## 1.1 プロジェクト目的

サッカー日本代表に関する情報を、

* 現在の代表
* 試合
* 大会
* 選手
* 監督
* 歴代代表
* 日本代表の歴史
* 統計データ

という複数の切り口から検索・閲覧できる総合情報サイトを構築する。

単純なニュースサイトではなく、

> **「日本代表の現在から過去までを調べられるデータベース＋クロニクル」**

を目指す。

---

# 2. サイトコンセプト

## キャッチコピー

> **日本代表のすべてが、ここにある。**

## 基本コンセプト

現在の試合情報を見るだけでなく、

「この選手はいつ代表になった？」

「この大会の代表メンバーは？」

「日本はこの国と何回対戦している？」

「歴代監督の成績は？」

「1998年の日本代表は誰だった？」

といった疑問を一つのサイト内で解決できることを目的とする。

---

# 3. 最重要ページ

トップページには以下の8セクションを配置する。

| セクション            | 内容       |
| ---------------- | -------- |
| 🔥 NEXT MATCH    | 次の代表戦    |
| ⚽ LAST MATCH     | 直近の試合    |
| 👤 CURRENT SQUAD | 現在の代表選手  |
| 📰 NEWS          | 最新ニュース   |
| 📅 SCHEDULE      | 今後の日程    |
| 🏆 TOURNAMENT    | 現在参加中の大会 |
| 📖 HISTORY       | 日本代表の歴史  |
| 📊 DATA          | 代表データ    |

---

# 4. トップページ要件

## 4.1 NEXT MATCH

次回の日本代表戦を最上位で表示する。

表示項目：

* 大会名
* 対戦国
* 日時
* 会場
* 開催地
* キックオフ時刻
* 試合までのカウントダウン

可能であれば、

* 日本代表エンブレム
* 対戦国エンブレム
* 大会ロゴ

を表示。

---

# 5. LAST MATCH

直近の試合結果を表示する。

表示項目：

* 日本
* 対戦国
* スコア
* 試合日時
* 大会名
* 会場
* 得点者
* 試合結果

試合詳細ページへのリンクを設置する。

---

# 6. CURRENT SQUAD

現在の代表選手を表示。

ポジション別に分類する。

```text
GK
DF
MF
FW
```

選手カードには、

* 写真
* 名前
* ポジション
* 所属クラブ
* 背番号

を表示。

クリックすると選手詳細ページへ遷移する。

---

# 7. NEWS

日本代表関連ニュースを表示。

基本的には、

* 最新ニュース
* 招集
* 試合
* 大会
* 選手
* 監督
* 移籍・所属クラブ関連

などを分類可能にする。

ニュース情報と公式データを混在させず、

**ニュース＝ニュース**

**データ＝データ**

として管理する。

---

表示項目：

* 日付
* 対戦国
* 大会
* 会場
* 開催地
* キックオフ

フィルター機能：

* 年
* 大会
* 対戦国
* ホーム / アウェイ

# 29. 開発原則

### 原則1

**まずデータ構造を作る。**

### 原則2

**UIとデータを分離する。**

### 原則3

**将来の年代別代表拡張を妨げない。**

### 原則4

**ニュースサイトではなくデータベースを中心にする。**

### 原則5

**情報量を増やしてもUIが破綻しない設計にする。**

### 原則6

**公式情報とユーザー独自情報を区別する。**

### 原則7

**存在しないデータをAIが推測して登録しない。**

---

# 30. 完成形

最終的には、

> **日本代表について調べたいなら、まずここを見る。**

というポジションを目指す。

「ニュースを見る」

だけではなく、

**調べる → 比較する → 掘り下げる → 歴史をたどる**

というユーザー体験を提供する。
