# 依頼文(固定・一字も変えずに両方式へ渡す)

「タイマー付きメモ帳」を作ってください。Windows で動く小さなアプリです。

## 作るもの
メモを書き、指定した時刻に知らせてくれるメモ帳です。機能は次の5つだけです。これ以外は作らないでください。

1. 追加: 本文(必須)と、通知時刻(省略可)を指定してメモを追加する
2. 一覧: 作った順(古い順)にメモを表示する
3. 削除: メモを1件選んで消す
4. 保存: アプリを閉じて開き直しても、メモが残っている(JSONファイルに保存)
5. 通知: 通知時刻になったメモを、1回だけ画面に知らせる

## 守ること(中心部分の仕様・変更不可)
中心部分は `src/core.mjs`(ES モジュール、外部パッケージ不要)に作り、次の名前と動きにしてください。画面はこの中心部分を呼ぶだけにしてください。

- `createStore(filePath)`: 保存先のJSONファイルを指定して、ストアを作る。ファイルが無ければ空で始める。ファイルが壊れていて読めない場合は、例外を出さず空で始め、壊れたファイルを `<filePath>.corrupt` に残す。
- `store.add({ text, remindAt })`: メモを追加し、追加したメモを返す。
  - メモは `{ id, text, createdAt, remindAt, notified }` の形。`id` は他と重ならない文字列。`createdAt` は追加時刻のISO文字列。`remindAt` は省略時 `null`、指定時はISO文字列。`notified` は最初 `false`。
  - `text` は前後の空白を取り除いて保存する。空(空白だけを含む)または201文字以上なら例外を出す。
  - `remindAt` が日付として読めない文字列なら例外を出す。`Date` オブジェクトも受け付け、ISO文字列にして保存する。
  - 追加するたびにファイルへ保存する。
- `store.list()`: メモの配列を、追加した順(古い順)で返す。返した配列を書き換えても、ストアの中身は変わらない。
- `store.remove(id)`: 消せたら `true`、そのidが無ければ `false`。消したあともファイルへ保存する。
- `store.due(now)`: `now`(Date)の時点で、通知時刻が `now` 以前で、まだ `notified` が `false` のメモの配列を返す。通知時刻が無いメモは含めない。
- `store.markNotified(id)`: そのメモの `notified` を `true` にして保存し、`true` を返す。idが無ければ `false`。

## 画面
- `index.html` を開くと使える、1枚の画面にしてください(ブラウザで開けば動く作りでよい。保存先は画面側で用意してよい)。
- 画面で、追加・一覧・削除ができ、通知時刻になったら画面に知らせが出ること。
- 日本語の表示にしてください。

## 終わりの目安(この4つがそろったら完成)
1. `node --test` で、あなたが書いたテストがすべて通る
2. 上の中心部分の仕様どおりに動く(別の人が用意したテストで確かめます)
3. 画面で、メモの追加・削除ができ、開き直しても残る
4. 画面で、通知時刻を過ぎたメモに知らせが1回だけ出る
